Thách thức chính của AI Agents

  • Hallucination: Agent dễ bịa thông tin khi thiếu dữ liệu.
  • Alignment: Khó kiểm soát agent hành động đúng ý muốn.
  • An toàn: Rủi ro lạm dụng để tấn công tự động.
  • Quyền riêng tư: Truy cập dữ liệu nhạy cảm làm tăng rò rỉ.
  • Chi phí: Tốn kém token và độ trễ (latency) cao.
